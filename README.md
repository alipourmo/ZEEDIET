# ZeeDiet

سامانهٔ مدیریت کلینیک تغذیه با رابط فارسی و راست‌چین (RTL)، ساخته‌شده با Laravel 13 و PHP 8.4.

## فقط دو محیط اجرا لازم است

**یک codebase داریم؛ نسخهٔ جداگانه یا شاخهٔ جدا برای هاست و Vercel لازم نیست.** تفاوت محیط‌ها فقط در تنظیمات دیتابیس و سرویس‌های اجراست:

| کاربرد | برنامه | پایگاه‌داده | وضعیت |
|---|---|---|---|
| اجرای محلی توسعه | PHP / Laravel | SQLite | توسعه و بررسی سریع |
| سرور/هاست اصلی | PHP-FPM، worker و scheduler | MySQL 8 | مسیر پیشنهادی برای استفادهٔ عملیاتی |
| آزمایش آنلاین | کانتینر FrankenPHP در Vercel | PostgreSQL در Supabase | محیط آزمایشی؛ اطلاعات واقعی وارد نشود |

Vercel + Supabase «نسخهٔ سوم برنامه» نیست؛ همان برنامه با تنظیمات آزمایشی است. راهنمای انتخاب و آماده‌سازی: [راهنمای محیط‌های اجرا](docs/deploy/README.md).

## قابلیت‌های برنامه

- پنل‌های مدیر/منشی، اپراتور، متخصص تغذیه و مراجعه‌کننده
- پروندهٔ مراجعان، اطلاعات پزشکی با دسترسی نقش‌محور، نوبت‌دهی و تقویم شمسی
- ثبت جلسات و اندازه‌گیری، گردش‌کار بررسی و انتشار گزارش، پیگیری و پرداخت
- ورود کارکنان با موبایل و رمز، ورود OTP مراجعه‌کننده، پیامک و ثبت رخدادهای حسابرسی

جزئیات محصول در [مشخصات سامانه](docs/SPEC.md) و راهنمای استفاده در [راهنمای فارسی](docs/user-guide-fa.md) است.

## پیش‌نیازها

- PHP 8.4 و Composer 2
- افزونه‌های PHP: `mbstring`, `intl`, `zip`, `openssl`, `tokenizer`, `xml`, `ctype`, `fileinfo`
- دیتابیس بر اساس محیط: `pdo_sqlite` برای توسعه، `pdo_mysql` برای سرور، یا `pdo_pgsql` برای Supabase

## اجرای محلی

```bash
cp .env.example .env
composer install
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

باز کنید: <http://127.0.0.1:8000/login>. Seed چهار حساب آزمایشی می‌سازد و رمز موقت هر حساب را فقط یک‌بار در ترمینال چاپ می‌کند؛ رمز مدیر برای شمارهٔ `09000000001` است. در نخستین ورود باید رمز جدید تعیین شود. برای دیدن صفحات، یک مراجعه‌کنندهٔ آزمایشی در پنل بسازید.

> `migrate:fresh --seed` تمام داده‌های دیتابیس فعال را پاک می‌کند. فقط از آن برای دیتابیس محلیِ قابل‌حذف استفاده کنید؛ برای Supabase یا سرور اصلی هرگز اجرا نکنید.

## انتشار

- **سرور/هاست اصلی:** [راهنمای استقرار PHP-FPM + MySQL](docs/deploy/vps-mysql.md) — شامل migration، صف، زمان‌بندی، backup، SSL و بازگشت نسخه.
- **آزمایش آنلاین:** [راهنمای Vercel + Supabase](docs/deploy/vercel-supabase-fa.md) — محیط آزمایشی با schema مجزا و PostgreSQL. OTP پیامکی به سرویس SMS واقعی نیاز دارد.

برای استقرار Vercel فعلاً لازم است مخزن را از داشبورد Vercel import کنید یا دسترسی پروژهٔ Vercel را برای اتصال Arena فراهم کنید. از این محیط آزمایشی برای دادهٔ واقعی مراجعان استفاده نکنید.

## تست و کیفیت کد

```bash
composer lint
composer stan
composer test
php scripts/verify-support.php
```

GitHub Actions سبک کد و تست‌ها را با SQLite، MySQL 8 و PostgreSQL 17 بررسی می‌کند. جزئیات CI در `.github/workflows/ci.yml` است.

## تنظیمات و امنیت

تنظیمات نمونه در [`.env.example`](.env.example) است. فایل `.env`، کلید `APP_KEY`، رمزهای دیتابیس و کلیدهای سرویس را commit نکنید. `APP_KEY` در هر محیط باید ثابت و محرمانه باشد. دیتابیس Supabase برای آزمایش است و فقط از schema `zeediet` استفاده می‌کند.
