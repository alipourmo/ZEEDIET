# راهنمای دمو (اجرای محلی)

این راهنما برای دیدن سامانه روی کامپیوتر خودتان است. برای نصب کامل و production به `docs/RELEASE.md` مراجعه کنید.

> **Vercel برای این دمو استفاده نمی‌شود.** کانتینر Vercel پایگاه‌داده ندارد، پس ورود کارکنان در آن کار نمی‌کند.

## پیش‌نیاز

- PHP 8.4 با افزونه‌های `mbstring`، `intl`، `zip`، `pdo_sqlite`، `openssl`، `tokenizer`، `xml`، `ctype`، `fileinfo`
- Composer 2
- Git

## ۱. دریافت و نصب

```bash
git clone https://github.com/alipourmo/ZEEDIET.git
cd ZEEDIET
git checkout arena/68aa0ded-zeediet
cp .env.example .env
composer install
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
```

در خروجی `migrate --seed` برای هر کارمند یک **رمز موقت** چاپ می‌شود. فقط یک بار نمایش داده می‌شود؛ آن را یادداشت کنید.

## ۲. اجرا

```bash
php artisan serve
```

سپس مرورگر را روی `http://127.0.0.1:8000/login` باز کنید.

## ۳. حساب‌های آزمایشی

| نقش | موبایل | ورود به |
|---|---|---|
| مدیر | `09000000001` | `/admin` |
| منشی | `09000000002` | `/admin` (بدون مدیریت کاربران و گزارش فعالیت) |
| اپراتور دستگاه | `09000000003` | `/operator` |
| متخصص تغذیه | `09000000004` | `/specialist` |

رمز هر حساب همان رمز موقتی است که در خروجی `migrate --seed` چاپ شد. در اولین ورود سامانه رمز جدید می‌خواهد.

## ۴. چه چیزهایی را ببینید

- **داشبورد:** `/admin` (نوبت‌های امروز، مراجعان جدید هفته)
- **مراجعه‌کنندگان:** `/admin/clients` و ثبت مراجعه‌کنندهٔ جدید از `/admin/clients/create`
- **تقویم:** `/admin/calendar` (روز، هفته و ماه شمسی)
- **پیامک‌ها:** `/admin/sms/log`
- **گزارش فعالیت‌ها:** `/admin/audit` (فقط مدیر)
- **پنل اپراتور:** `/operator` با حساب اپراتور
- **پنل متخصص:** `/specialist` با حساب متخصص

## نکته‌های مهم

- **داده نمونه نیست.** بعد از نصب هیچ مراجعه‌کننده‌ای وجود ندارد. برای دیدن پرونده و نوبت، یک مراجعه‌کننده در `/admin/clients/create` بسازید.
- **پنل مراجعه‌کننده (`/my-account`) کامل نمی‌شود.** ورود با کد پیامکی است. در اجرای محلی پیامک در فایل `storage/logs/sms.log` نوشته می‌شود، ولی کد آن پنهان است (`[کد]`). پس نمی‌توان با کد واقعی وارد شد.
- **اگر رمزها را از دست دادید:** `php artisan migrate:fresh --seed` همهٔ داده‌ها را پاک و دوباره می‌سازد.
- **فایل `database/database.sqlite` فقط روی همین کامپیوتر است** و در Git ثبت نمی‌شود.
