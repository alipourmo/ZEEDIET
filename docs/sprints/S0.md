# Sprint S0 — Bootstrap

Status: **partial**. The Laravel 13 project, the RTL layout and the preview pages are in place. Verification is pending: the first CI run and the first Vercel build. The Vercel deploy is blocked (see Verification).

## Built

- **S0-T1 (mostly):** Laravel 13 project from the official skeleton. `composer.json` requires PHP 8.4 (pending owner decision) and Laravel 13, with Pest 5, Pint and Larastan. `config/app.php` uses `Asia/Tehran`, `fa` and `fa_IR` (faker). `config/clinic.php` (name, weekend days `[6]`, reminder hours, contraindication keys, holiday stub, OTP and password settings). `.env.example`. `.gitignore`. CI workflow (`.github/workflows/ci.yml`: Pint, PHPStan level 6, Pest). `phpstan.neon`.
- **S0-T2 (partial):** RTL `lang="fa"` layout (`resources/views/layouts/app.blade.php`), Vazirmatn (400/500/700) self-hosted in `public/fonts/vazirmatn` with the OFL licence, CSS tokens from spec section 11 in `public/css/app.css`, components `card`, `button`, `badge`, and the `/_styleguide` page (local only).
- **S0-T3 (partial):** `App\Support\Digits`, `App\Support\Jalali`, `App\Support\Mobile`, `App\Support\Display`. Blade directives `@fa`, `@jdate`, `@money` (in `AppServiceProvider`). Input normalisation runs in the preview controller only. The middleware is not written yet.
- **S0-T4:** `README.md`, `docs/DECISIONS.md`, `docs/BACKLOG.md`, this note, and `docs/SPEC.md`.
- **Vercel preview (testing only):** `Dockerfile` (FrankenPHP, PHP 8.4), `Caddyfile` (document root `public`, `noindex` header), `vercel.json` (container service, catch-all rewrite), `.dockerignore`. Routes: `/` (home), `/tools/jalali`, `/tools/mobile`, `/healthz`, `/robots.txt`. No database.

## Deviations

- Jalali conversion is in-house for now rather than `morilog/jalali` (see DECISIONS).
- Laravel 13 instead of Laravel 11 (owner approved). PHP 8.4 instead of 8.3 is required by Pest 5 and is pending owner decision (see DECISIONS).
- The preview has no database and uses array cache and session. The spec's MySQL is not used for it.
- Not yet written: input-normalising middleware, full component set, `preventLazyLoading()`, self-hosted Chart.js.
