# Sprint S0 — Bootstrap

Status: **complete, pending CI on this branch**. All S0 tasks are in place. The four S0 acceptance checks are covered by tests. The Vercel deploy is manual and not part of S0 acceptance.

## Built

- **S0-T1 (mostly):** Laravel 13 project from the official skeleton. `composer.json` requires PHP 8.4 and Laravel 13 (owner approved), with Pest 5, Pint and Larastan. `config/app.php` uses `Asia/Tehran`, `fa` and `fa_IR` (faker). `config/clinic.php` (name, weekend days `[6]`, reminder hours, contraindication keys, holiday stub, OTP and password settings). `.env.example`. `.gitignore`. CI workflow (`.github/workflows/ci.yml`: Pint, PHPStan level 6, Pest). `phpstan.neon`.
- **S0-T2:** RTL `lang="fa"` layout (`resources/views/layouts/app.blade.php`), Vazirmatn (400/500/700) self-hosted in `public/fonts/vazirmatn` with the OFL licence, CSS tokens from spec section 11 in `public/css/app.css`, components `card`, `button`, `badge`, `flash`, and the `/_styleguide` page (local only).
- **S0-T3:** `App\Support\Digits`, `App\Support\Jalali`, `App\Support\Mobile`, `App\Support\Display`. Blade directives `@fa`, `@jdate`, `@jdatetime`, `@money` (in `AppServiceProvider`). `App\Http\Middleware\NormalizeInput` runs on the web group for query strings, form and JSON bodies (password fields excluded, see DECISIONS).
- **S0-T4:** `README.md`, `docs/DECISIONS.md`, `docs/BACKLOG.md`, this note, and `docs/SPEC.md`.
- **Vercel preview (testing only):** `Dockerfile` (FrankenPHP, PHP 8.4), `Caddyfile` (document root `public`, `noindex` header), `vercel.json` (container service, catch-all rewrite), `.dockerignore`. Routes: `/` (home), `/tools/jalali`, `/tools/mobile`, `/healthz`, `/robots.txt`. No database.

## Deviations

- Jalali conversion is in-house for now rather than `morilog/jalali` (see DECISIONS).
- Laravel 13 instead of Laravel 11, and PHP 8.4 instead of 8.3 (owner approved; Pest 5 needs 8.4). See DECISIONS.
- The preview has no database and uses array cache and session. The spec's MySQL is not used for it.
- The full component set from spec section 11 (table, modal, pagination and others) and self-hosted Chart.js are not written yet. They are needed in S1 and later sprints, and are listed in BACKLOG.
