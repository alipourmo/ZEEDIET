# Sprint S0 — Bootstrap

Status: **partial**. The helpers and docs are done and verified. The Laravel skeleton, CI and the UI base are not.

## Built

- **S0-T3 (helpers):** `app/Support/Digits.php`, `app/Support/Jalali.php`, `app/Support/Mobile.php`.
  - `Digits::toAscii` converts Persian and Arabic-Indic digits and maps Arabic ي/ك to ی/ک. `Digits::toPersian` does the reverse for display.
  - `Jalali` converts Gregorian ↔ Jalali, checks leap years and month lengths, parses user input (Persian digits, `/` or `-`), and formats Gregorian dates as Jalali.
  - `Mobile::normalize` accepts +98…, 0098…, 0…, bare 9… and Persian/Arabic digits, and returns `09xxxxxxxxx` or `null`.
- **S0-T1 (partial):** `config/clinic.php`, `.env.example`, `composer.json` (Laravel 11, Pest 3, Pint, Larastan), `.gitignore`.
- **S0-T4:** `README.md`, `docs/DECISIONS.md`, `docs/BACKLOG.md`, this note, and `docs/SPEC.md` (the build specification, kept as the source of truth).

## Verification

- `php scripts/verify-support.php` passes on PHP 8.3 (no Composer required): 32 checks. They include Nowruz anchors, leap-year edges, input parsing, mobile accept/reject cases, and a round trip over every day from 1900 to 2100 (73,414 days).
- The Pest tests in `tests/Unit/Support/` contain the same cases. They have **not** been run by Pest yet, because Composer cannot reach Packagist from the build sandbox.
- Pint, PHPStan and the CI workflow have **not** been run.
